## 4. Personality preservation rule

When a historical board has a superseded species/body but the same named character and stable personality wording:

1. split `VISUAL_IDENTITY` from `PERSONALITY_TEXT`;
2. supersede only the disproven visual fields;
3. retain personality text as CORROBORATED/CANDIDATE according to cross-source support;
4. never delete the entire character atom because one visual field was wrong.

This directly prevents the previous loss pattern.
