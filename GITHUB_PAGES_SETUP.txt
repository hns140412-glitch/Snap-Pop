탐험가의 아이디어 노트 — GitHub Pages PWA 테스트판

[가장 쉬운 배포 방법]
1. GitHub에서 새 저장소를 하나 만듭니다.
   예: idea-expedition

2. 이 ZIP을 압축 해제합니다.

3. 압축 해제한 폴더 안의 파일 전체를 저장소 최상위(root)에 업로드합니다.
   중요: idea_expedition_github_pages 폴더 자체를 한 단계 더 넣는 것이 아니라
   index.html이 저장소 첫 화면에서 바로 보여야 합니다.

   올바른 구조:
   repository/
   ├─ index.html
   ├─ app.js
   ├─ styles.css
   ├─ config.js
   ├─ manifest.webmanifest
   ├─ sw.js
   ├─ .nojekyll
   └─ assets/

4. GitHub 저장소:
   Settings > Pages

5. Build and deployment:
   Source = Deploy from a branch
   Branch = main
   Folder = /(root)
   Save

6. 잠시 뒤 GitHub Pages 주소가 생깁니다.
   예:
   https://YOUR-USERNAME.github.io/idea-expedition/

[PWA 설치]
- Android Chrome/Edge: GitHub Pages 주소 접속 > 브라우저 메뉴 > 앱 설치/홈 화면에 추가
- Windows Edge/Chrome: 주소창 오른쪽의 앱 설치 아이콘 또는 메뉴 > 앱 설치
- iPhone/iPad Safari: 공유 > 홈 화면에 추가

[Google Calendar OAuth]
GitHub Pages 주소가
https://YOUR-USERNAME.github.io/idea-expedition/
라면 Google Cloud Console > OAuth Web Client > Authorized JavaScript origins 에는
https://YOUR-USERNAME.github.io
만 등록합니다.
경로 /idea-expedition 는 origin에 넣지 않습니다.

[카메라]
GitHub Pages는 HTTPS로 제공되므로 모바일/PC 브라우저에서 getUserMedia 카메라 테스트가 가능합니다.
브라우저에서 카메라 권한을 허용해야 합니다.

[업데이트]
이후에는 새 프로젝트를 만들 필요가 없습니다.
같은 저장소의 index.html / app.js / styles.css / assets 등을 새 버전으로 덮어쓰고 Commit하면
같은 GitHub Pages 주소가 업데이트됩니다.

[캐시]
PWA 업데이트 직후 예전 화면이 남으면:
1. 앱을 완전히 종료 후 다시 실행
2. 브라우저 새로고침
3. 필요 시 설치된 PWA 제거 후 다시 설치
