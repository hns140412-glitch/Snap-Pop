탐험가의 아이디어 노트 v5 UI/기능 점검

[UI 적용]
- 첨부 시안에서 추출/재가공한 양피지 texture 사용
- 첨부 시안에서 추출/재가공한 wood texture 사용
- 첨부 시안의 잎/덩굴 분위기를 반영한 좌우 foliage overlay 사용
- 지도는 별도 map.svg, 탐험가 초상은 explorer.svg로 텍스트와 분리
- 아이디어/감정/묘사/관점/마무리 아이콘 SVG 분리
- 한글 폰트: Gowun Batang + Song Myung + Gowun Dodum
- 모든 제목/버튼/본문 텍스트는 실제 HTML text이며 이미지에 포함되지 않음

[기능 검사]
- app.js Node syntax check 통과
- sw.js Node syntax check 통과
- manifest JSON parse 통과
- HTML onclick 함수와 JS 함수 연결 검사 통과
- JS getElementById 정적 대상과 HTML ID 검사 통과
- HTML/CSS asset 경로 존재 검사 통과
- CSS brace balance 검사 통과
- 25레벨/EXP/5종 보석/지도 해금/기록/달력/백업/Google Calendar OAuth 기능 유지

[배포 주의]
- Google Calendar 실제 OAuth 성공 여부는 Netlify production URL을 Google Cloud Console Authorized JavaScript origins에 등록한 뒤 실제 계정으로 최종 확인 필요
- 브라우저는 Google Fonts를 네트워크에서 로드하며, 실패하면 Apple SD Gothic Neo / Malgun Gothic 계열 fallback 사용
