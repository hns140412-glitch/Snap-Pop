탐험가의 아이디어 노트 v8 BRIGHT FANTASY

수정사항
1. 탐험 완료(report) 화면에서 하단 지도/기록/+/보석함/설정 탭 표시
2. report 화면 하단 padding 추가하여 탭과 버튼 겹침 방지
3. 시작 화면의 탐험 시작 클릭 영역과 하단 탭 영역 분리
4. 홈 고밀도 일러스트 밝기/중간톤/채도 개선
5. 비홈 화면을 밝은 청록 하늘 + 에메랄드 숲 + 황금빛 양피지 팔레트로 변경
6. 등록 화면 일러스트도 밝게 조정
7. 카메라/필터 화면 밝기 조정
8. Service Worker cache를 v8로 변경하여 이전 UI 캐시 제거

사용
- Windows: START_WINDOWS.bat
- 종료: STOP_WINDOWS.bat
- 브라우저에서 이전 화면이 보이면 앱 창을 완전히 닫고 START_WINDOWS.bat을 다시 실행
