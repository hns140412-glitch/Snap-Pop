- 5가지 글쓰기 도움은 Lv.1부터 모두 사용 가능 (레벨 잠금 제거)
- 이름 등록 화면에 실제 웹 카메라/앨범 선택 추가
- 실사 모드: 얼굴 형태를 바꾸지 않고 색감/명암/비네팅 중심
- 일러스트 모드: 브라우저 Canvas 기반 색면 단순화 효과 (AI 얼굴 재생성 아님)
- 촬영 프로필을 localStorage에 저장하고 HUD/프로필에 반영
- 카메라 미지원/권한 거부 시 모바일 파일 촬영 input으로 fallback
