탐험가의 아이디어 노트 v7 — 고밀도 일러스트 + 카메라 필터 수정

핵심 변경
- 승인한 UI 시안의 홈 화면을 실제 고해상도 WEBP 일러스트 자산으로 사용
- 기존 단순 map.svg는 홈 화면에서 더 이상 사용하지 않음
- 5가지 글쓰기 도움은 Lv.1부터 모두 선택 가능
- 홈 화면의 실제 클릭 기능은 일러스트 위 투명 HTML 버튼으로 연결
- 등록 화면도 승인 시안의 고밀도 프레임을 실제 배경 자산으로 사용
- 이름 입력/사진 버튼은 실제 HTML 컨트롤로 배경 위에 배치
- 촬영 후 필터가 적용되지 않던 문제 수정
- 촬영 원본(base canvas)을 별도로 보관하고 필터 선택 때마다 다시 렌더링
- 실사/일러스트 모드 모두 촬영 후 변경 가능
- 원본/따뜻한/빈티지/숲의 빛/모험가 5개 필터 썸네일 자동 생성
- 얼굴 좌표나 얼굴 형태를 변형하지 않아 유사도를 우선 유지
- Windows START_WINDOWS.bat / STOP_WINDOWS.bat 유지

실행
1. ZIP 압축 해제
2. START_WINDOWS.bat 더블클릭
3. Edge 앱 창 또는 기본 브라우저에서 실행
4. 종료는 STOP_WINDOWS.bat

카메라
- localhost 또는 HTTPS에서 사용
- 권한이 거부되면 앨범/촬영 파일 선택으로 fallback
