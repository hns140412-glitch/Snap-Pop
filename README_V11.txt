탐험가의 아이디어 노트 V11 — Dual Theme Edition

핵심 변경
1. 기본 테마: 판타지 어드벤처
   - 밝은 하늘, 화사한 탐험 지도, 게임형 HUD 중심
   - 사용자가 선호한 두 번째 컨셉을 기본값으로 지정

2. 보조 테마: 스토리북 탐험
   - 첫 번째 컨셉의 흰색 면적을 크게 줄임
   - 양피지, 연한 녹색, 자연색 카드로 조정

3. 설정 > 화면 테마에서 즉시 전환
   - 판타지 어드벤처 / 스토리북 탐험
   - 선택값은 localStorage에 저장되어 다음 실행에도 유지

4. UI 문구 정리
   - 일부 이모지 문구 제거
   - 레벨 기본 명칭을 '첫발견 탐험가'로 정리
   - 앱 정보 V11 / 백업 버전 11 반영

5. PWA 캐시 버전 갱신
   - idea-expedition-v11-dual-theme
