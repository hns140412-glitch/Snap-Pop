탐험가의 아이디어 노트 v9 — UI 구조/카메라 필터 수정

핵심 수정
- 승인 시안 전체 스크린샷을 배경으로 쓰는 방식 제거
- 승인 시안에서 '지도 일러스트 부분만' 별도 home-map-pure.webp 자산으로 사용
- HUD / 제목 / 탐험 시작 / 하단 탭은 실제 HTML UI로 분리
- 중복 HUD/중복 버튼 문제 제거
- 홈 한 화면 내에서 시작 버튼과 하단 탭이 겹치지 않도록 grid 레이아웃 재구성
- 5가지 글쓰기 도움은 처음부터 모두 사용 가능
- 완료 화면에서도 하단 탭 유지
- 보석함/콘텐츠 화면 밝은 판타지 팔레트 보강

카메라/필터
- 촬영 원본 Canvas를 보관하고 필터를 누를 때마다 원본에서 다시 렌더링
- 실사 필터 차이를 더 분명하게 강화
- 일러스트 모드는 단순 색감 필터가 아니라:
  1) 색면 posterization
  2) luminance edge detection
  3) 윤곽선 overlay
  4) storybook warm glaze
  를 적용
- 실사 ↔ 일러스트 모드는 촬영 후에도 즉시 재렌더링

주의
- 브라우저 내부 필터이므로 생성형 AI처럼 모자/탐험가 의상을 새로 합성하지는 않음
- 대신 얼굴 구조를 바꾸지 않아 유사도 유지에 유리함
